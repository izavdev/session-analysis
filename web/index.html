How privacy works on GitHub Pages

Reports and session files you open or drop here are read only in your browser’s memory. Their names and contents are not sent to GitHub or any other server, and this viewer does not save them in browser storage.

GitHub serves the website and its public demo files. Loading the site needs a connection; inspecting your own files does not upload them. GitHub Pages logs visitors’ IP addresses for security purposes. GitHub Pages documentation

The downloadable demo report and session are intentionally public. Review your own reports before publishing or sharing them.
